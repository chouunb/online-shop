# Online Shop

Интернет-магазин, разработанный на Django.

Проект создан в учебных целях для изучения backend-разработки и постепенно развивается.

## Возможности

- регистрация и авторизация пользователей
- личный кабинет
- изменение профиля
- загрузка аватара
- смена темы оформления
- каталог товаров
- корзина
- оформление заказа
- отзывы к товарам
- поиск
- пагинация
- административная панель Django
