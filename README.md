# Online Shop

Интернет-магазин, разработанный на Django.

Проект создан в учебных целях для изучения backend-разработки и постепенно развивается.

## Возможности

- регистрация и авторизация пользователей
- личный кабинет
- изменение профиля
- загрузка аватара
- смена темы оформления
- каталог товаров
- корзина
- оформление заказа
- отзывы к товарам
- поиск
- пагинация
- административная панель Django



## Стек технологий

Backend
- Python
- Django

Frontend
- HTML
- CSS
- JavaScript

База данных
- PostgreSQL

Дополнительно
- Git
- GitHub
- python-dotenv


## Реализовано

### Пользователи

- регистрация
- авторизация
- выход из аккаунта
- изменение профиля
- загрузка аватара

### Каталог

- просмотр товаров
- категории
- поиск
- пагинация

### Корзина

- добавление товаров
- изменение количества
- удаление товара

### Отзывы

- создание
- удаление

### Администрирование

- управление товарами
- управление пользователями
- управление отзывами


## В планах

- REST API
- Docker
- Redis
- избранное
- оплата
- рекомендации товаров
